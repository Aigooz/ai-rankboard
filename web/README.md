# AI 排行榜 Web

纯静态网页端，无需后端或构建。优先读取同目录的 `leaderboards.json`，失败后尝试主仓库、更新通道及镜像快照；不是实时评测服务。

## 功能与数据说明

- 收藏与最多 4 个模型的对比选择存储于当前浏览器的 localStorage，不上传、不跨设备同步。存储损坏会安全回退；权限/容量限制时本次会话仍可操作并提示无法保存。
- 独立对比页按所选的**同一个榜单**展示原始成绩；本榜未收录或缺失的分数不补零，不计算跨榜综合分。
- 支持搜索、厂商、许可、开发者国内/国外/未知归属和只看收藏的组合筛选。归属不是 API 部署位置；未知厂商不会被误归为国外。
- 手机端以模型卡片展示榜单；对比表和能力矩阵保留可键盘聚焦的横向滚动。与 Android 并非功能完全一致，本次不提供中转站工具/地址历史。
- 来源信息默认仅占紧凑一行，显示来源、抓取日期和必要的过期/失败小标记；点击“来源与指标说明”才展开完整指标、链接与三个独立时间。无历史时不显示历史面板，有记录时默认折叠。来源名称与可选榜单由快照动态生成，不限制 Aider、EvalPlus 等新增来源。
- 主页优先展示筛选和模型排名，统计图表与 LiveBench 能力矩阵移至榜单后默认折叠，避免手机先滚过多屏图表。
- 榜单显示来源链接、指标解释，以及**快照生成时间 / 本榜成功抓取时间 / 上游评测版本与更新时间**三个独立概念。48 小时过期提示仅针对抓取缓存年龄，不保证上游成绩新鲜。
- 兼容现有 schemaVersion 3 旧快照；可选消费 `board.health`、`board.metric`、`board.source`、`board.evaluation` 和 `snapshot.historyByBoard`。旧快照未提供的版本、时间和历史明确显示缺失，绝不使用快照时间冒充上游更新时间。
- HLE 模型评分榜已移除。“推理”默认展示快照中的首个榜单（当前为 LiveBench 推理）；保留默认折叠的“HLE 测评说明与公开示例（无评分榜）”，消费可选 `benchmarkReferences.hle`。参考资料与当前推理榜成绩无关，仅展示一条官网公开 Ecology 题干，保留作者、出处、许可限制、canary 和禁止训练提醒，不显示答案、不下载或镜像受限题库。
- 历史仅来自真实成功抓取记录。仅在最近两次记录具有相同非空 `evaluationVersion` 时展示名次/成绩变化；版本未知或切换只展示时间线。历史可能只保留 Top 100，因此缺失模型不推断为退榜。
- 不将不同榜单成绩混合排名；场景推荐按各独立榜单展示前两名。雷达为各榜样本内 min-max 相对位置（不是百分位），不计算跨榜均值。
- 行业资讯在应用自身浮层原生展示标题、日期和 `news.articles[].content` 纯文本段落，不嵌入原站、不为阅读请求第三方页面。正文来自后端抓取快照，可能滞后或截断至 8000 字符；不执行正文中的 HTML/脚本。旧快照或正文缺失时显示“正文未获取”，保留“打开原文”按钮。原文入口仅接受 `https://artificialanalysis.ai/articles/<slug>`。
- 阅读器支持按需“翻译为中文”，点击后将标题和正文分块发送至第三方 MyMemory，显示“机器翻译，仅供参考”，可切换原文。分块不超过 450 UTF-8 字节，串行请求，失败可重试，关闭阅读器取消未完成请求。成功分块仅缓存在当前页面内存，刷新清除；不预翻译或上传未点击的文章。免费服务可能限流、额度不足或不可用，机器翻译可能不准确。
- 混合价格为 `(输入 ×3 + 输出) ÷4`，USD 暂按固定 7.2 换算人民币，仅供估算。任一价格分量缺失不补零，未知币种不作人民币报价。

## 本地运行

```bash
npx --yes http-server web -p 8080 -c-1
```

打开 `http://127.0.0.1:8080`。也可使用正确返回 JavaScript MIME 的其他静态服务器（包括 `.mjs`）；无需安装项目依赖。

## 独立测试

需 Node.js 18+，在仓库根目录运行：

```bash
node --test web/tests/*.test.mjs
node --check web/app.js
```

覆盖存储异常与损坏、4 模型上限、同榜数据隔离、厂商归属、来源链接安全、抓取过期判定、旧快照渲染和可选健康/历史字段兼容。
